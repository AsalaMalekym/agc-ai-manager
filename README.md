# AG|C Gaming News 3.1

Рабочий Worker: **vkgropwithgpt**. Панель: https://vkgropwithgpt.woen2017.workers.dev/

## Контент

Вместо мемов — игровые новости, релизы, обзоры по материалам разработчиков и подборки. Рубрика определяется содержанием поступившей статьи. Обзоры не выдаются за собственное прохождение; подборки создаются только если исходник содержит несколько игр и подтверждённые особенности. Нет обязательной квоты постов или обещания выпускать все рубрики каждый день.

Официальные источники: PlayStation Blog (`https://blog.playstation.com/feed/`) и Xbox Wire (`https://news.xbox.com/en-us/feed/`). Это две конкретные ленты, а не весь игровой интернет. Новые источники добавляются в `src/news.js` после проверки их принадлежности и формата.

Cron проверяет ленты **каждую минуту** круглосуточно с HTTP ETag/Last-Modified. Реальная задержка зависит от обновления RSS, Cloudflare, очереди и скорости DeepSeek; мгновенная доставка от момента появления страницы не гарантируется. Первое успешное чтение каждого источника запоминает существующие записи без публикации архива. Недоступность одной ленты не останавливает вторую. При переполненной очереди источник не помечается обработанным.

Каждый новый материал проходит:

1. Проверку HTTPS, разрешённого домена, даты (не старше 72 часов), наличия текста. DTD/внешние XML-сущности запрещены; размер ответа ограничен.
2. Создание краткого русского заголовка и 2–4 фактов по исходнику. Для каждого требуется существующая в исходнике цитата. Слухи, нерелевантные материалы и повторы пропускаются.
3. Отдельный вызов DeepSeek: сверка каждого утверждения, дат, чисел, платформ, регионов и условий. Проверяющий тоже обязан привести точные цитаты. Неполный/неопределённый результат запрещает публикацию.
4. Модерацию готового текста и добавление ссылки на официальный источник с датой.

Проверка соответствия первоисточнику не является гарантией истинности самого источника или безошибочности ИИ. Маркетинговые обещания должны передаваться как заявления разработчика. Нет выдуманных результатов прохождения или независимых оценок.

Новости сейчас **текстовые**. Генерация картинок отключена: права на загрузку фотографий для стены не подтверждены. Текст отправляется через `VK_USER_TOKEN`, если он задан; иначе через существующий `VK_TOKEN` сообщества. После неоднозначного ответа VK автоматических повторов нет. Реальная доступность wall.post подтверждается успешным ответом VK с post_id, а не наличием ключа или зелёным health.

## Общение и модерация

Сохранены ответы на сообщения сообщества и обращения в комментариях; промпт обновлён на игровую тематику. Для актуальных фактов бот получает последние проверенные публикации, а при нехватке данных должен это признать. Подписки Callback: `message_new`, `wall_reply_new`.

Входящие сообщения и ответы проходят модерацию. Сомнительные комментарии и вложения уходят на ручную проверку. Удаление уверенно запрещённого комментария требует `AUTO_DELETE=on` и отдельного пользовательского токена; с одним ключом сообщества используется список проверки. Баны автоматически не выполняются.

Аналитика запрашивается раз в сутки в 23:30 МСК. `wall.get` может не поддерживать имеющийся тип токена: в этом случае аналитика недоступна. Это не источник новостей. `TREND_GROUP_IDS` относится только к прежней аналитике, генератор новостей его не использует.

## Надёжность и расходы

SQLite Durable Object хранит очередь, историю и журнал. ID новости — SHA-256 URL, повторные события не создают дубли. Дополнительная проверка ИИ сопоставляет материал с последними публикациями, но не гарантирует выявление всех одинаковых событий из разных источников.

Задания старше 15 минут отменяются; после перезапуска незавершённая отправка считается неопределённой и включает паузу. STOP проверяется перед записью в VK. Возобновление отменяет накопленную очередь. Старые задания мемов после обновления пропускаются.

По умолчанию 250 вызовов DeepSeek в сутки UTC: обычно три на новость и три на ответ. Неограниченной генерации нет. При исчерпании бюджета материал пропускается; на следующий день квота восстанавливается. Непрошедшая фактчек новость пропускается, не останавливая остальные. Три последовательных технических сбоя или неопределённая отправка включают паузу для диагностики. Обычный опрос лент ИИ не расходует.

Дедупликация хранится 30 дней, история — 100 постов, журнал — 200 записей, очередь — до 100 заданий. Лимиты ответов: 10 новых событий на пользователя в час и 100 суммарно. Исходные сообщения удаляются после обработки. Секреты не записываются в журнал.

## Настройка

Существующие секреты сохраняются (`keep_vars=true`). Развёртывается только `vkgropwithgpt`, другие Workers и DNS не меняются.

| Переменная | Назначение |
| --- | --- |
| `DEEPSEEK_API_KEY` | Имеющийся ключ DeepSeek |
| `DEEPSEEK_MODEL` | По умолчанию deepseek-chat |
| `VK_GROUP_ID` | Положительный ID сообщества |
| `VK_TOKEN` | Имеющийся ключ сообщества: сообщения, комментарии, попытка текстовой публикации |
| `VK_USER_TOKEN` | Необязательный пользовательский токен, предпочтительный для wall.post и необходимый для удаления комментариев |
| `VK_CALLBACK_SECRET` | Секрет сервера Callback, одинаковый в ВК и Worker |
| `VK_CONFIRMATION_CODE` | Код подтверждения Callback |
| `AGC_ADMIN_KEY` | Случайный ключ панели не короче 24 символов; поддерживается прежний AGC_TEST_KEY |
| `KILL_SWITCH` | Только off разрешает работу |
| `MAX_AI_CALLS_PER_DAY` | Общий лимит ИИ; по умолчанию 250 |

Секреты добавляются в Cloudflare → Worker → Settings → Variables and Secrets с типом Secret. Без `AGC_ADMIN_KEY` автоматика работает, но вход в панель закрыт. Не публикуйте токены в исходниках или переписке.

В панели: STOP/возобновление, «Проверить новости сейчас», неопубликованный предпросмотр, проверка DeepSeek, аналитика и журнал. Ручной запуск проверки использует тот же ID минуты, что и cron; он не публикует архив и не обходит проверки.

Публичный `/health` показывает конфигурацию, результат чтения источников и ссылку на последнюю успешно опубликованную новость. `postingActive=true` означает готовность конфигурации, но не успешный вызов VK. Все управляющие маршруты `/api/*` требуют ключ администратора.

## Проверка и развёртывание

```sh
npm ci
npm run check
npx wrangler deploy --dry-run --config wrangler.toml
npm run smoke
```

GitHub Actions проверяет код, тестирует настоящий workerd с SQLite Durable Object, собирает и развёртывает production, затем проверяет live-маршруты и защиту API. Unit/runtime-тесты используют подмены провайдеров, а не реальные публикации в сообществе. RSS проверены отдельным чтением настоящих источников.

Откат: Cloudflare Deployments или возврат коммита. Не удаляйте миграцию SQLite/старый KV. При срочной остановке установите KILL_SWITCH=on.
